# 🍹 Juicy Scroll Animation Website

An interactive scroll animation website with smooth video-controlled scrolling, modern UI, and a responsive design.

## 🚀 Features

- Smooth scroll-based animation
- Video controlled by scroll progress
- Modern and clean UI
- Responsive design
- Interactive landing page experience

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 📂 Project Structure

The main website files are available inside the `Juicy website` folder.

## ▶️ How to Run

1. Download or clone this repository.
2. Open the `Juicy website` folder.
3. Open `index.html` in your browser.
4. For the best experience, use VS Code with the Live Server extension.

## 🎯 Project Purpose

This project was created to demonstrate how scroll interactions can control animations and videos to create an engaging modern website experience.
